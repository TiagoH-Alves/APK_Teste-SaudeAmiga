# SaúdeAmiga - App de Teste para Automação
Este aplicativo foi desenvolvido especificamente para fins didáticos e de **testes de automação**. Ele simula uma interface de cadastro de uma plataforma de saúde chamada "SaúdeAmiga", oferecendo um ambiente controlado e padronizado para a prática de scripts de automação móvel sem armazenar nenhum dado
